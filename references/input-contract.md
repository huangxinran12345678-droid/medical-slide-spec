# 医学PPT内容输入合同

## 目标

让第①接单Skill、第②资料准备Skill和本Skill可以独立运行，也能无缝衔接。优先接收两份UTF-8
Markdown或纯文本；文件名可以变化，但标题和字段含义保持稳定。

## 输入一：《需求确认单》

至少包含：

```text
项目名称：
主题或拟定标题：
PPT类型：
本次要产生的真实结果：
使用场景：
核心受众：
汇报目的：
页数或汇报时长：
客户大纲/必须章节：
禁止改写内容：
内容补全模式：授权补全／真实资料严格／完整模拟
隐私处理：
联网许可：已允许／未允许／不需要
证据等级：E0／E1／E2／E3
必须核验的医学主张：
医学审核人或审核状态：
交付时间：
参考文件用途：视觉参考／内容结构参考／二者都有／无
```

视觉参考只记录是否由使用者另行提供，不记录风格描述。若文件同时承担内容结构参考，提取目录、
页数、评分表、必须章节和禁用内容；不要提取配色、字体、版式和装饰。

## 输入二：《资料预检清单》

每份资料至少记录：

```text
资料名称：
文件类型与版本：
用途：客户事实／内容结构／医学依据／视觉参考
可读状态：完整／部分可读／不可读
内容范围：
真实性状态：客户最终版／客户草稿／未核实线索／公开证据
证据可用性：可直接支持／需联网复核／仅作线索／不适用
禁止改写字段：
缺失页或缺失字段：
隐私处理：已去标识化／需处理／不涉及
格式转换或OCR状态：
备注：
```

## 缺少标准包时的回退

1. 先读完聊天和现有资料；
2. 在内部建立同等字段；
3. 只询问无法推断且会改变内容的项目；
4. 不要求使用者补做文件形式；
5. 不因视觉参考缺失而停止。

证据等级可以由本Skill根据内容风险判定，不要求客户理解分级。E2、E3未获联网许可时仍可整理
草稿，但必须保留证据阻断项，不能进入内容冻结。

标准包是优先输入，不是强制前置条件。
