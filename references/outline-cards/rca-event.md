# 护理不良事件RCA大纲卡

## 卡片身份

- 大纲卡ID：`rca_event`
- 版本：v11.0
- 任务家族：质量安全
- 基础内容路由：`outline_custom`

## 适用条件

- 围绕一个已发生的护理或医疗质量安全事件开展结构化复盘；
- 需要重建事件流程，区分直接原因、促成因素和系统根因；
- 结果是形成对应根因的系统行动并追踪残余风险，而不是追责个人。

## 不适用与易混淆

- 一般低指标或流程改进选`pdca_qi`；
- 有品管圈组织与十步骤选`qcc`；
- 前瞻识别尚未发生的流程失效模式属于HFMEA/FMEA，不属于本轮核心14卡。

## 必需输入

- 去标识化事件报告、分级、患者结局和立即处置；
- 人员访谈、制度、设备、环境、交接、排班和流程证据；
- 事件时间线、调查团队、根因验证依据和行动计划；
- 责任部门、时限、监测指标、追踪结果和保密要求。

## 标准目录

前置页：封面、复盘目标与保密边界、目录。

1. `01 事件概况、分级与立即处置`
2. `02 去标识化事件时间线`
3. `03 调查团队与资料来源`
4. `04 事件流程重建`
5. `05 直接原因与促成因素`
6. `06 根本原因及验证依据`
7. `07 系统性改进措施`
8. `08 责任人、时限与监测指标`
9. `09 改进后追踪与残余风险`
10. `10 经验教训与推广`

## 常见变体

- 科室内部复盘：强化事实、流程和短期行动，减少比赛式包装；
- 严重事件RCA：强化多部门证据、系统根因、督办和残余风险；
- 去标识化教学案例：明确为模拟或脱敏案例，不披露责任人身份。

- 20页：前置3；概况处置2、时间线2、资料1、流程2、因素2、根因2、措施3、追踪1、经验1；收尾1。
- 30页：前置3；概况处置3、时间线3、资料2、流程4、因素3、根因4、措施5、追踪2、经验1；收尾0。

30页如需参考依据或致谢，必须从正文分配中腾出页面，不可突破固定页数。

## 内容闭环

`事件概况 → 立即处置 → 事件时间线 → 流程重建 → 直接原因 → 促成因素 → 系统根因及验证 → 系统行动 → 责任与时限 → 监测 → 残余风险 → 经验推广`

## 典型页面任务

- 事件事实、处置时间线、预期流程与实际流程对照；
- 促成因素分组、根因证据链、根因—行动矩阵；
- 责任时限、监测计划、追踪结果和残余风险。

## 禁止伪造

- 事件等级、患者结局、访谈、制度缺陷、责任认定、整改完成和追踪结果；
- 患者/员工身份、内部事件编号、未授权截图和个人追责性结论。

## 外部优先与边界

国家和本院不良事件制度、保密要求及调查结论优先。RCA页面必须使用系统视角；授权补全
只能提出待核实的分析框架和行动建议，不得改写正式调查事实。
