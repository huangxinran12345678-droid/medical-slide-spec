# 护理查房大纲卡

## 卡片身份

- 大纲卡ID：`nursing_round`
- 版本：v11.0
- 任务家族：临床病例
- 基础内容路由：`nursing_case`

## 适用条件

- 以一位当前或近期患者为中心开展护理业务查房、专科查房或现场讨论；
- 结果是共同评估、护理判断、床边查体、措施优化和团队总结；
- 需要保留疾病知识、病例、护理评估、护理问题及措施的对应关系。

## 不适用与易混淆

- 以学习者能力和教学评价为结果时选`nursing_teaching_round`；
- 以完整案例价值、创新、效果和反思参赛时选`nursing_case`；
- 行政查房、夜查房和节假日查房不是本卡默认结构，使用变体或定制大纲。

## 必需输入

- 查房目的、参与者、时长、患者阶段和讨论重点；
- 去标识化病史、诊疗时间线、评估、量表、检验与当前护理问题；
- 已实施措施、监测、效果和床边查体记录；缺失部分必须标待确认；
- 客户要求的查房制度、模板和护长总结形式。

## 标准目录

前置页：封面、查房目的、目录。

1. `01 疾病知识`
2. `02 病例介绍`
3. `03 护理评估`
4. `04 护理问题、目标、措施及评价`
5. `05 护士床边查体`
6. `06 讨论及护长总结`

收尾页：参考文献、致谢。

## 常见变体

- 临床业务查房：压缩疾病知识，强化当前风险、交接重点和现场决策；
- 专科查房：强化专科评估、操作、循证依据和难点处理；
- 疑难/危重查房：强化临床冲突、多学科权衡、升级条件和讨论题。

## 页数分配

- 12页：前置2；疾病1、病例2、评估1、问题措施3、查体1、讨论1；收尾1。
- 16页：前置3；疾病1、病例2、评估2、问题措施3、查体1、讨论2；收尾2。
- 20页：前置3；疾病2、病例3、评估2、问题措施4、查体1、讨论2；收尾3。
- 30页：前置3；疾病3、病例4、评估4、问题措施7、查体2、讨论3；收尾4。

页数为初始方案。护理问题较多时优先增加“问题—目标—措施—监测—评价”闭环页，
不把多个问题压入一页。

## 内容闭环

`查房目的 → 临床冲突 → 病例时间线 → 护理评估 → 护理问题及依据 → 目标 → 措施 → 动态监测 → 效果 → 床边查体 → 讨论与护长总结`

每个问题必须能追溯到评估依据，措施和监测必须对应目标，真实效果只来自可核对记录。

## 典型页面任务

- 病例钩子、诊疗时间线、异常指标、评估结论；
- 单个护理问题闭环、动态监测、床边查体路径；
- 讨论题、护长总结、可迁移经验。

## 禁止伪造

- 已实施护理、查体阳性发现、患者结局、目标达成和护长原话；
- 病历截图、签名、住院号、医院证明和未经核实的专科操作记录。

## 外部优先与边界

优先服从本院查房制度、客户指定目录和内容结构要求。授权补全可提供建议查体方案、讨论题和
待核实护理内容，但不得冒充真实执行。逐页内容继续由v12门禁裁决。
