# 循证护理与证据转化大纲卡

## 卡片身份

- 大纲卡ID：`evidence_translation`
- 版本：v11.0
- 任务家族：科研循证
- 基础内容路由：`outline_custom`

## 适用条件

- 从明确临床问题出发，检索和评价证据，并在本地实践中实施；
- 包含审查标准、基线审查、障碍/促进因素、转化策略、再审查和持续性；
- 结果不是单纯文献汇报，而是证据到实践的闭环。

## 不适用与易混淆

- 只说明一项新技术的准入条件时选`new_technology_project`；
- 单纯系统评价/Meta分析或Journal Club不属于本轮核心14卡；
- 一般指标改进但没有证据检索和审查标准时选`pdca_qi`。

## 必需输入

- 临床问题/PICO、利益相关者、检索策略和纳入证据；
- 证据质量评价、最佳证据、审查标准和本地适配依据；
- 基线审查、障碍/促进因素、实施策略和过程记录；
- 再审查数据、效果、适宜性、可行性和持续性计划。

## 标准目录

前置页：封面、临床问题与PICO、目录。

1. `01 项目团队与利益相关者`
2. `02 证据检索`
3. `03 证据质量评价`
4. `04 最佳证据与审查标准`
5. `05 本地情境差距与基线审查`
6. `06 障碍与促进因素`
7. `07 证据转化策略`
8. `08 实施过程`
9. `09 再审查与效果`
10. `10 可行性、适宜性、持续性与推广`

## 常见变体

- JBI式证据实施：强化审查标准、基线、障碍、行动与再审查；
- 循证护理项目汇报：强化PICO、证据等级、临床适配和护理结局；
- 比赛型成果：增加评分映射、实施证据、创新边界和答辩追问。

- 16页：前置3；团队1、检索2、评价1、标准1、基线1、障碍1、策略1、实施2、再审查1；收尾2。
- 20页：前置3；团队1、检索2、评价2、标准2、基线2、障碍1、策略2、实施2、再审查1；收尾2。
- 30页：前置3；团队2、检索3、评价3、标准3、基线3、障碍2、策略3、实施4、再审查2；收尾2。

## 内容闭环

`临床问题/PICO → 利益相关者 → 证据检索 → 质量评价 → 最佳证据 → 审查标准 → 本地差距 → 基线审查 → 障碍/促进因素 → 转化策略 → 实施 → 再审查 → 可行性/适宜性/持续性`

## 典型页面任务

- PICO、检索流程、证据等级、推荐意见；
- 证据—审查标准映射、基线差距、障碍与策略矩阵；
- 实施时间线、再审查结果、持续性和推广边界。

## 禁止伪造

- 检索结果、证据等级、专家共识、基线审查、实施覆盖率和再审查效果；
- 项目团队、机构支持、伦理、培训和可持续性证明。

## 外部优先与边界

现行证据实施框架、专业指南、本院情境和真实审查数据优先。证据推荐不能自动证明本地
实施成功；逐页内容继续由v12完整性、密度和冻结门禁裁决。
