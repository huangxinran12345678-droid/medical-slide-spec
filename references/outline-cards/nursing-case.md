# 护理个案大纲卡

## 卡片身份

- 大纲卡ID：`nursing_case`
- 版本：v11.0
- 任务家族：临床病例
- 基础内容路由：`nursing_case`

## 适用条件

- 完整呈现一个病例的专科护理价值、个体化判断、循证措施和效果；
- 常用于专科护士汇报、案例分享、个案比赛或经验沉淀；
- 结果强调护理难点、创新亮点、结局、局限和可复制经验。

## 不适用与易混淆

- 以当前患者床边共同评估和护长讨论为主时选`nursing_round`；
- 以学习者能力为结果时选`nursing_teaching_round`；
- 医生主导的诊断挑战或罕见病例报告不属于本轮核心14卡，使用定制大纲。

## 必需输入

- 案例选择理由、病例时间线、专科护理难点和去标识化资料；
- 评估依据、护理问题、目标、措施、动态调整、结局和反思；
- 创新内容的来源、授权、适用范围和可复制条件；
- 比赛通知、评分表、时长和必须页面。

## 标准目录

前置页：封面、案例价值、目录。

1. `01 患者资料及就医时间线`
2. `02 关键临床问题与护理难点`
3. `03 系统护理评估`
4. `04 护理问题及依据`
5. `05 护理目标与个体化计划`

## 常见变体

- 专科护理案例：强化专科评估、操作和证据；
- 比赛型个案：增加评分维度、记忆锚点、创新边界和答辩追问；
- 经验分享型个案：减少比赛包装，强化可复制流程和失败反思。

## 内容闭环

`案例价值 → 病例时间线 → 护理难点 → 系统评估 → 护理问题及依据 → 个体化目标 → 循证措施 → 动态调整 → 效果与结局 → 创新边界 → 局限反思 → 可复制经验`

## 典型页面任务

- 案例钩子、病程时间线、风险优先级、问题依据配对；
- 单项护理闭环、动态调整、效果趋势和目标达成；
- 创新证据、限制条件、失败边界和迁移清单。

## 禁止伪造

- 实施记录、患者原话、效果指标、结局、获奖情况和创新应用结果；
- 虚构循证来源、病例图片、医院证明、伦理或知情同意材料。

## 外部优先与边界

比赛评分表、专科规范、客户事实和真实随访优先。授权补全可以形成待确认的完整护理方案，
但客户版必须可替换，不能反向声称来自病历。逐页内容继续由v12门禁裁决。
