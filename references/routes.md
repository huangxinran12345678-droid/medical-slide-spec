# 四类医学PPT内容合同

v11用`outline_card_id`决定显式目录和类型专属闭环，用`base_content_route`决定是否复用本文件。
`outline_custom`直接使用卡片闭环，不强套以下四条合同，但仍执行v12内容完整性、密度、证据和冻结门禁。

显式目录与内容闭环分开。闭环用于检查每页有没有回答关键问题，不机械显示成目录标题。

## 护理查房/病例 `nursing_case`

闭环：

`临床冲突或风险 → 病例时间线 → 护理评估 → 护理问题及依据 → 护理目标 → 循证措施 → 动态监测 → 效果与目标达成 → 反思`

逐项回答：

- 患者为何值得汇报，主要风险或护理难点是什么；
- 入院、诊疗、护理和转归按什么顺序发生；
- 哪项评估发现什么异常，量表、时间、单位和风险等级是什么；
- 每个护理问题依据哪些症状、体征、量表或风险；
- 每个问题的短期/长期目标和观察指标是什么；
- 每项措施做什么、为何做、频率/时机和注意事项是什么；
- 监测什么、何时监测、什么阈值触发升级处理；
- 指标如何变化，目标达成、部分达成还是未达成；
- 哪些判断有效、哪些不足、如何改进。

对应性验收：每个问题可追溯到评估依据，每个目标对应一个问题，每项核心措施对应目标，监测与
风险一致，效果评价使用可比较指标。真实效果、转归和患者原话只来自客户资料；建议或模拟必须标明。

## PDCA质量改进 `pdca_qi`

闭环：

`指标定义 → 基线 → 目标 → 原因候选 → 真因验证 → 对策 → 实施 → 过程指标 → 结果 → 标准化与持续监测`

逐项回答：

- 指标名称、分子、分母、单位、周期和纳入排除标准；
- 改进前水平、样本量和时间范围；
- 目标值、截止时间和依据；
- 原因候选与验证数据，明确确认或排除；
- 每个对策对应哪个真因、负责人、时间、资源和衡量方式；
- 实际实施内容、关键节点和覆盖率；
- 证明对策执行的过程指标；
- 改善前后同口径结果、变化量和不确定性；
- 固化措施、反弹监测和遗留问题。

失败条件包括：只有原因罗列没有真因验证；只有百分比没有分母、样本量或时间；对策与真因无法
对应；只有结果没有实施和过程指标；把模拟改善率当成真实成绩。

## 医学教学/培训 `medical_teaching`

闭环：

`受众问题 → 学习目标 → 常见误区 → 知识框架 → 判断/操作流程 → 病例应用 → 易错点与风险 → 练习/后测 → 总结`

逐项回答：

- 学员当前不会什么，为什么需要学习；
- 学完后能识别、判断、解释或执行什么；
- 常见误区是什么，后文如何纠正；
- 核心概念及其关系是什么；
- 实际遇到问题时按什么顺序判断或操作；
- 如何把前述框架用于具体情景；
- 禁忌、红旗征象和升级条件；
- 如何验证学员会应用而非只会记忆；
- 最终带走的2–3个可执行记忆点。

学习目标必须可观察、可评价；病例应用和后测必须覆盖目标；剂量、阈值、操作和禁忌需核验适用范围。

## 科研汇报/答辩 `research_defense`

闭环：

`研究缺口 → 研究问题 → 方法 → 样本流程 → 主要结果 → 解释 → 局限 → 结论 → 评委追问`

逐项回答：

- 已知什么、未知什么、为何值得研究；
- PICO/PECO、假设或主要目标；
- 设计、对象、变量、结局、偏倚控制和统计方法；
- 纳入、排除、失访和分析集；
- 主要结局、效应量、不确定性、单位和样本量；
- 结果与既往证据如何一致或不同；
- 偏倚、精度、缺失、外推和设计限制；
- 数据实际支持什么结论；
- 最可能被质疑的方法、统计和外推边界。

研究问题、设计、变量、分析集、结果和结论必须对应。不要只报P值，不要把非显著解释成无差异，
不要把相关或预测结果表述为因果。

## 场景修饰

真实比赛才补充比赛级别、评分表、评委关注、汇报时长、证据支持的创新点和可能追问。普通科室
汇报不添加空洞的“比赛感”。场景修饰只改变内容重点，不产生视觉效果控制。
