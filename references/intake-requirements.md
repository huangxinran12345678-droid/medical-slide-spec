# 医学PPT内容要求收集

## 原则

先读资料，后补问题。只询问资料中没有、且会改变文字内容、真实性或页序的项目。

不要询问视觉风格、颜色、字体、版式、模板效果、动画或装饰。没有参考模板时照常工作。

## 必须明确

- 主题、PPT类型和本次要产生的真实结果；
- 使用场景、汇报目的和核心受众；
- 页数或汇报时长；
- 客户大纲、必须章节、比赛评分或其他内容结构要求；
- 已提供资料、最终版/草稿状态和禁止改写内容；
- 真实病例、项目、研究和效果数据是否齐全；
- 必须引用的指南、论文、制度或教材；
- 是否包含现行指南、剂量、阈值、禁忌、操作、器械、公开统计或科研核心主张；
- 内容补全模式和不得补全的客户事实；
- 联网许可；
- 隐私处理与医学审核人；
- 参考文件用途：视觉参考、内容结构参考、二者都有或无；
- 截止时间。

## 参考文件处理

- 视觉参考：只记录“由使用者另行提供给下游视觉AI”，不分析效果；
- 内容结构参考：读取目录、页序、文字、评分表和必须章节；
- 二者都有：只处理内容结构部分；
- 无：继续生成内容，不推荐通用视觉路线。

## 默认值

只有在不会改变真实事实时使用：

| 项目 | 默认值 |
|---|---|
| 内容补全 | 授权补全 |
| 语言 | 简体中文 |
| 隐私 | 去标识化 |
| 首轮交付 | 客户确认草稿 |
| 引用 | 医学主张就近脚注，末尾列主要参考 |
| 证据等级 | E1；命中高风险或科研条件时自动升级 |

页数、主题、受众、目的、大纲、补全权限和真实数据不是可静默默认的字段。证据等级不得为了
减少检索而降级。

## 最小补问

1. 汇总已识别要求；
2. 一次性列出其余关键缺口；
3. 给出必要的填写提示；
4. 不重复问已确认项；
5. 不把视觉参考状态作为内容生成门禁。

## 允许生成草稿的最低条件

- 主题、目的、受众和场景明确；
- 页数或时长明确；
- 大纲来源或可用路由明确；
- 内容补全边界和禁止改写内容明确；
- 真实患者隐私处理明确；
- 已判定证据等级；E2、E3没有联网许可时已列明阻断项，没有把未核验主张写成确定结论。

允许生成草稿不等于允许冻结。冻结还需明确确认，同时清零所有待确认项和未完成证据项。
