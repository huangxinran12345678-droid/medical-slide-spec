# 逐页完整内容合同

## 固定章节

客户确认稿按以下顺序组织：

1. `【项目参数】`
2. `【版本与内容状态】`
3. `【输入资料与补全边界】`
4. `【显式目录与页数分配】`
5. `【内容逻辑约束（不作为目录标题）】`
6. `【逐页完整内容】`
7. `【待确认事项汇总】`
8. `【主要资料与医学审核】`

不要加入视觉方向、模板画像、版式、颜色、字体、容器、区域比例或图标说明。

## 版本与状态

草稿使用：

```text
- 文档用途：客户确认
- 内容状态：待确认
- 内容版本：vXX
- content_lock_id：待确认
- 确认记录：未确认
- 待确认项总数：具体整数
- 未完成证据项总数：具体整数
```

冻结终版由脚本改为`已冻结`并写入内容锁。不要人工编造内容锁。

## 每页固定格式

### 封面

```text
第1页｜封面

【页面可见内容】
- 主标题：
- 副标题：无／实际副标题
- 正文：
  • 汇报者、科室、机构、日期等实际显示信息
- 核心结论：无
- 表格：无
- 图表数据：无
- 来源脚注：本页无外部医学主张

【内容说明（不进入PPT）】
- 所属目录章节：前置页
- 页面类型：封面
- 页面任务：识别主题与汇报身份
- 内容性质：客户已提供／联网核验／建议补全-待核实／完整模拟
- 证据状态：不涉及外部医学主张／客户事实／客户资料支持／已联网核验／完整模拟／待核验
- 待确认项：无／逐项写明
- 不得改动：
```

### 第2页及以后

```text
第X页｜唯一可见标题

【页面可见内容】
- 正文：
  • 写出页面实际显示的完整句子、标签和数字
- 核心结论：写出实际显示的一句话；不使用时写“无”
- 表格：无／完整Markdown表格
- 图表数据：无／完整数据字段
- 来源脚注：具体短来源／本页无外部医学主张

【内容说明（不进入PPT）】
- 所属目录章节：
- 页面类型：目录／章节过渡／普通内容／病例事实／框架关系／图表数据／表格／操作宣教／总结／参考文献／其他
- 页面任务：只写一个内容任务
- 内容性质：
- 证据状态：不涉及外部医学主张／客户事实／客户资料支持／已联网核验／完整模拟／待核验
- 待确认项：无／逐项写明
- 不得改动：
```

除封面外不设置独立副标题字段。页码行中的标题就是实际标题。

## 表格完整性

- 使用Markdown表格；
- 写全列名、行名和全部单元格；
- 各行列数一致；
- 单元格不得只写“待补”“同上”“略”；
- 表格过大时拆页或删减，不规定版式。

## 图表数据完整性

需要数据图表时写：

```text
- 图表数据：
  • 数据关系：趋势／比较／构成／相关／效果量／其他
  • 分类或时间：
  • 系列：
  • 数值：
  • 单位：
  • 样本量或统计口径：
  • 数据来源：
```

不规定图表类型、颜色、尺寸、位置或装饰。缺少真实、已授权或模拟数据时不得让下游AI补造。

## 待确认项

草稿中逐页写清具体字段、当前处理和需要谁确认。不得只写“部分数据待确认”。全局汇总应能与
逐页项目一一对应。

冻结前，每页必须写`待确认项：无`且`证据状态`不得为`待核验`，全局必须同时满足
`待确认项总数：0`与`未完成证据项总数：0`。被客户接受的建议或模拟内容仍应在`内容性质`中
保留其真实属性，不能因客户接受就改写成客户原始事实。

`【输入资料与补全边界】`还必须记录：

```text
- 证据等级：E0／E1／E2／E3
- 证据等级判定依据：本项目为何属于该等级
- 必须核验的医学主张：无／逐项列出
- 联网许可：已允许／未允许／不需要
- 联网核验状态：不需要／客户资料已核验／已联网核验（YYYY-MM-DD）／未授权-待核验／已授权-未完成
- 证据冻结状态：可冻结／阻断
```

E3项目在`【主要资料与医学审核】`中必须提供`核心主张证据映射`和`检索日期`。映射至少给出
页面或主张、直接支持来源、年份/版本、适用人群与支持关系，并保留DOI、PMID或官方URL之一。
