# v11 医护PPT大纲路由

## 使用顺序

1. 先执行既有优先级：客户明确大纲 → 内容结构参考中的硬性目录 → v11大纲卡 → 联网定制。
2. 判断本次任务要产生的真实结果，不只看疾病名、科室名或材料形式。
3. 从下表选择一个主大纲卡；混合任务只能指定一个主卡，其他卡作为局部补充。
4. 读取主卡全文，按`outline-card-contract.md`建立选择记录、显式目录和初始页数方案。
5. 再读取主卡指定的基础内容路由；`outline_custom`直接使用卡内闭环。
6. 完成逐页内容后执行v12内容密度与完整性门禁，全部通过后才能冻结页序。

## 六大家族与14张核心卡

| 任务家族 | 大纲卡ID | 主判断 |
|---|---|---|
| 临床病例 | `nursing_round` | 围绕当前患者开展共同评估、床边查体和护理讨论 |
| 临床病例 | `nursing_teaching_round` | 借病例培养可评价的临床能力 |
| 临床病例 | `nursing_case` | 完整呈现一个病例的专科护理价值、效果与反思 |
| 质量安全 | `pdca_qi` | 围绕指标或流程完成一般质量改进循环 |
| 质量安全 | `qcc` | 具有圈组织、十步骤和有形/无形成果 |
| 质量安全 | `rca_event` | 从一个具体不良事件追溯系统根因并防止复发 |
| 教育沟通 | `patient_education` | 让患者或照护者改变行为并知道何时求助 |
| 教育沟通 | `nursing_training` | 让医护学习者掌握可评价的知识、判断或操作 |
| 科研循证 | `research_proposal` | 研究尚未实施或尚无结果，证明问题、方案与可行性 |
| 科研循证 | `research_defense` | 已有研究结果，解释方法、结果、局限与结论 |
| 管理职业 | `annual_report` | 复盘过去周期的岗位、团队、指标与工作结果 |
| 管理职业 | `job_competition` | 证明岗位匹配度并提出上岗后的可执行计划 |
| 科研循证 | `evidence_translation` | 把最佳证据转化为本地实践并完成审查与再审查 |
| 项目准入 | `new_technology_project` | 争取新技术/新项目准入、验收或推广 |

卡片文件清单和校验词以`outline-cards/manifest.json`为机器可读真源；执行时只读取命中的
一张卡，避免把14类全文同时载入上下文。

## 第一轮类型判断

按以下顺序判断：

1. 核心对象是一位患者或病例吗？
   - 当前住院护理决策、床边查体和团队讨论：`nursing_round`；
   - 以学习者能力为结果：`nursing_teaching_round`；
   - 以专科价值、个体化、效果和反思为结果：`nursing_case`。
2. 核心对象是指标、流程或安全事件吗？
   - 有圈名、圈员、圈会和十步骤：`qcc`；
   - 从一个已发生不良事件追溯根因：`rca_event`；
   - 其他指标或流程改进：`pdca_qi`。
3. 核心结果是教育吗？
   - 患者/家属能行动、自我管理和识别危险信号：`patient_education`；
   - 医护学习者获得可考核能力：`nursing_training`。
4. 核心结果是研究或证据吗？
   - 尚无研究结果，申请开题或说明研究方案：`research_proposal`；
   - 已有研究结果，需要答辩或成果汇报：`research_defense`；
   - 从证据检索进入本地实施、审查和再审查：`evidence_translation`。
5. 核心对象是个人或科室吗？
   - 回顾过去完成情况：`annual_report`；
   - 争取未来岗位并说明上岗计划：`job_competition`。
6. 核心结果是争取技术或项目准入、验收、推广吗？选择`new_technology_project`。

## 易混淆裁决

### 护理查房／教学查房／护理个案

- 是否保留床边共同评估不是唯一标准；先看结果是当前护理决策、学习能力还是案例价值。
- 比赛型护理个案不得因出现“查体”就误选护理查房。
- 教学查房必须有学情、可评价目标、教学活动和评价，不能只在普通查房前加“教学目标”。

### PDCA／品管圈／RCA

- 有品管圈组织身份和十步骤才选`qcc`，不能把普通PDCA包装成品管圈。
- 有具体不良事件、事件重建和系统根因才选`rca_event`，不能把一般低指标问题写成RCA。
- 其他以指标、基线、真因、对策、过程和结果为主的改进选择`pdca_qi`。

### 健康宣教／护理培训

- 患者版本从“我该怎么做、何时求助”出发；专业培训从学习目标、判断/操作和考核出发。
- 同一疾病主题可生成两种不同大纲，受众和预期行为决定卡片。

### 科研开题／科研答辩

- 无真实结果时必须选`research_proposal`，不得拟造结果来套答辩结构。
- 已完成研究以方法—结果—解释—局限—结论为主时选`research_defense`。

### 述职／竞聘

- 述职回答“过去完成了什么、为何未完成、下一周期怎么改”；
- 竞聘回答“为什么是我、上岗后做什么、如何证明可行”。

### 循证转化／新技术新项目

- 循证转化必须有PICO、证据质量、本地差距、障碍、实施和再审查；
- 新技术项目重点是原理、适用范围、团队资质、安全、合规、资源和准入请求。

## 冲突与无匹配处理

- 客户指定目录与卡片不同：保留客户目录，使用卡片只做缺口检查并记录覆盖项。
- 同时命中两张卡且会改变一级目录：一次性询问“这次更看重哪一个最终结果”，不静默合并。
- 一项任务同时含病例与教学：只选一个主卡，另一个作为局部内容修饰，不建立双目录。
- 临床病例报告/罕见病例、MDT、指南解读、文献汇报等不属于本轮14张核心卡；使用
  `standard-outlines.md`或取得联网许可后定制，不强行套入相邻卡。
- 比赛评分表、本院制度、主办方内容结构要求和客户硬性目录始终高于通用卡。
