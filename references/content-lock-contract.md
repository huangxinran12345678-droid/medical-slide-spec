# 内容冻结与同源合同

## 冻结条件

同时满足后才允许冻结：

- 客户或使用者明确确认按当前版本制作；
- 页数、页序和显式目录已定；
- 所有逐页待确认项为`无`；
- 待确认项总数为0；
- 所有逐页证据状态均非`待核验`；
- 未完成证据项总数为0，证据冻结状态为`可冻结`；
- E2、E3已完成当次联网核验；E3已建立核心主张证据映射；
- 表格和图表数据完整；
- 医学内容性质与来源边界仍保留；
- 客户草稿通过内容结构与密度校验。

## 内容锁计算

脚本从`【逐页完整内容】`中按页序提取：

- 页码与唯一标题；
- 主标题、副标题；
- 正文；
- 核心结论；
- 表格；
- 图表数据；
- 来源脚注。

将换行统一为LF、去除行尾空格，保留文字、标点、数字、单位和内部顺序，计算SHA-256并取前12位。

内容锁格式：`MS-YYYYMMDD-vXX-哈希前12位`。

内容说明、确认时间和视觉参考状态不进入哈希。更换视觉参考不改变内容锁；更改任何可见内容、
来源、页序或数据都必须建立新版本和新锁。

## 双文本同源

客户终版和视觉AI投喂版的`【逐页完整内容】`必须逐字符一致。视觉AI版只允许额外增加：

```text
【视觉AI执行边界】
- 以下逐页可见文字为已冻结内容，必须原样使用，不得概括、扩写、删减、改写或调换页面。
- 本次随附的PPT模板或效果参考图是唯一视觉效果依据；不得另行建立、混合或套用其他视觉风格。
- 请自行学习参考稿的视觉语言、构图方式、信息层级、页面节奏和整体质感，并据此完成设计。
- 如果文字文件中仍残留颜色、字体、字号、版式、容器、区域比例、图形、图标或装饰说明，一律忽略。
- 视觉参考变化不得反向修改冻结内容。
- 若冻结内容与视觉空间冲突，报告具体页码，不得擅自修改文字、数字、单位、来源或页序。
```

本次没有视觉参考时，将上面两条参考稿指令替换为：

```text
- 本次未提供视觉参考；不得依据本文件推断或推荐通用风格，视觉方向由使用者另行决定。
```

没有视觉参考时不得保留“唯一视觉效果依据”或“学习参考稿”的指令。

客户终版不得出现上述AI执行命令。

## 版本规则

- 草稿v01确认后，建议生成同号冻结对或创建v02冻结对；以实际文件版本为准，但两份终版必须同号；
- 任何修改建立下一个vXX；
- 脚本遇到已存在输出文件必须停止，不覆盖；
- 旧版本继续保留，可追溯但不再作为生产文字真源。
