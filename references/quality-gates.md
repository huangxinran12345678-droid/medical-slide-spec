# 医学PPT内容冻结质量门禁

## 1. 输入门禁

- 已优先读取需求确认单和资料预检清单；缺少时已从现有资料建立同等信息；
- 主题、结果、场景、受众、页数/时长和大纲来源明确；
- 补全权限、禁止改写内容、隐私、联网和医学审核边界明确；
- 已判定E0–E3证据等级并写明判定依据和必须核验主张，升级条件没有被降级处理；
- 参考文件用途已区分，但视觉参考缺失没有阻止内容工作；
- 没有询问或推荐视觉风格。

## 2. 大纲与专业闭环

- 大纲优先级正确，只选择一个主卡；
- 目录章节、页数分配和逐页归属一致；
- 专业闭环用于内容检查，没有机械变成目录；
- 每页只有一个主要内容任务；
- 护理、质量改进、教学、科研或卡片专属闭环完整且相互对应。

## 3. 逐页完整性

- 每页具有完整可见文字，不是概要；
- 第2页起只有页码行中的一个标题；
- 表格写全表头和单元格；
- 图表数据写全关系、分类/时间、系列、数值、单位、样本量/口径和来源；
- 来源脚注存在且能核查；
- 页面类型、内容性质、待确认项和不得改动项完整；
- 每页证据状态完整，待核验页面与全局未完成证据项计数一致；
- 所有页面通过内容密度门禁。

## 4. 真实性与医学边界

- 客户事实、联网证据、建议补全、模拟内容和待提供内容没有混淆；
- 客户接受建议不等于建议变成客户原始事实；
- 未补造病历、签名、伦理批件、项目成绩和文献；
- 当前指南、剂量、阈值、禁忌、操作、器械和公开统计已按证据等级处理；
- E2、E3在冻结前已完成当次联网核验；E3核心主张已绑定可定位来源和支持关系；
- 正式使用前仍需合格人员进行医学审核。

## 5. 草稿门禁

- 内容状态为`待确认`；
- content_lock_id为`待确认`；
- 确认记录为`未确认`；
- 待确认项总数与逐页非`无`项目一致；
- 未完成证据项总数与逐页`待核验`项目一致；证据未完成时冻结状态为`阻断`；
- 只交付客户确认稿，不生成可投入视觉AI的冻结终版。

## 6. 冻结门禁

- 存在明确确认记录；
- 待确认项总数为0，每页待确认项为`无`；
- 未完成证据项总数为0，每页证据状态均非`待核验`，证据冻结状态为`可冻结`；
- E2、E3的联网核验状态包含当次检索日期；E3存在核心主张证据映射及DOI、PMID或官方URL；
- 客户终版与视觉AI投喂版版本一致；
- 两份文件的逐页完整内容逐字符一致；
- 两份文件的content_lock_id一致且能由内容重新计算；
- 视觉AI版只增加最小执行边界，没有视觉效果微操；
- 有参考时明确其为唯一视觉效果依据，并要求学习参考稿的视觉语言、构图、层级、节奏和质感；
- 视觉AI版明确忽略文字文件中可能残留的颜色、字体、字号、版式、容器、区域比例、图形、
  图标和装饰说明；
- 无参考时不推荐或推断通用风格，也不出现“唯一视觉效果依据”或“学习参考稿”的指令；
- 客户终版不出现Kimi、提示词或AI执行命令；
- 输出文件此前不存在，没有覆盖旧版本。

## 7. 禁止的视觉控制字段

活动输出不得出现以下章节或字段：

- 参考模板画像；
- 视觉设计系统；
- 页面设计判定；
- 页面原型；
- 容器策略；
- 区域实现或区域占比；
- 布局与阅读顺序；
- 图标预算；
- 字体、颜色与强调；
- 动画与视觉焦点。

普通自然语言中的视觉微操同样禁止，例如“本页采用蓝色卡片”“使用左右分栏布局”或
“图标放在标题右侧”；不得通过取消字段名绕过门禁。

“视觉参考由使用者另行提供”只说明外部责任，不构成视觉控制。

## 8. 自动校验

先将当前`SKILL.md`所在目录解析为`<SKILL_DIR>`。以下示例中的`python`代表可用的Python 3
启动命令；环境只提供`python3`或Windows Python Launcher时相应替换，不要写死盘符或用户名。

大纲库：

```text
python "<SKILL_DIR>/scripts/validate_outline_library.py"
```

草稿：

```text
python "<SKILL_DIR>/scripts/validate_content_package.py" draft "<客户确认稿.txt>" --route nursing_case --mode authorized --outline-card nursing_round
```

冻结对：

```text
python "<SKILL_DIR>/scripts/validate_content_package.py" locked "<客户终版.txt>" --ai "<视觉AI投喂版.txt>" --route nursing_case --mode authorized --outline-card nursing_round
```

校验通过只证明文字包结构、内容密度和同源锁通过，不证明医学终审、视觉生成、PPT可编辑性或客户验收。
